# Jeff

把想说的中文，翻译成更得体的中文。

Jeff 是一个 macOS 菜单栏沟通助手。选中文字、框选聊天截图，或输入一段处境描述后，即可获得改写、回复或分析建议，并在结果浮窗中切换用途、补充背景和重新生成。

有些话意思没错，发出去却容易让人不舒服。Jeff 想帮你保留原意，把催进度、提意见、拒绝请求这些难开口的话，说得清楚一点，也给对方留一点余地。你也可以选中收到的消息，看看对方可能在意什么、自己该怎么接话。

例如，你准备发：

> 怎么还没给我？我这边一直等着呢。

可以换成：

> 想确认一下这份材料大概什么时候方便给我？我这边需要接着往下推进，如果有卡点我们可以一起看看。

这是表达方向的示例，实际结果取决于上下文、所用模型和服务。得体不等于一味退让，拒绝和边界也可以说清楚。

## 下载与安装

首版支持 **macOS 14 及以上、Apple Silicon 芯片**。暂不提供 Intel 版本。

[下载预览版](https://github.com/Chulan-824/Jeff/releases) · [反馈问题](https://github.com/Chulan-824/Jeff/issues)

下载并双击 `Jeff-版本号-macos-arm64.dmg`，在打开的安装窗口中，将左侧的 `Jeff.app` 拖到右侧“Applications”文件夹。复制完成后，从“应用程序”打开 Jeff，再推出安装磁盘。启动后常驻菜单栏，可从图标菜单进入设置。

更新前请先退出正在运行的 Jeff；Finder 提示同名应用时，确认后替换。旧版 Release 的 ZIP 仍需解压后手动将应用拖入“应用程序”。

当前发布的是预览版，使用 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证。macOS 可能阻止首次打开。确认下载来源后，可按系统“隐私与安全性”中的提示处理；若组织策略禁止运行，请遵循设备管理要求。

安装包不包含 API Key。首次使用需要配置自己的模型服务，相关调用费用由服务提供方收取。

## 使用方法

1. 从菜单栏打开“设置”中的“服务”，填写 Base URL、模型名称和 API Key。可使用 DeepSeek、OpenAI 或其他兼容 Chat Completions 流式接口的服务。
2. 点击“验证连接”，保存配置。
3. 在聊天窗口、文档或编辑器中选中文字，按 `⌥⌘D` 获取建议。需要读取选中文字时，请为 Jeff 授予辅助功能权限。
4. 文字无法选中时，按 `⌥⌘S` 框选截图。系统要求屏幕录制权限时，按提示授权并重新打开应用。

### 取词与处理动作

也可以从菜单栏选择“处理剪贴板文字”或“输入内容…”。划词、截图和剪贴板取得有效文字后立即处理；手动输入后点击“开始处理”。

取词方式与处理动作分开。结果浮窗顶部提供“自动 / 改写 / 回复 / 分析”：

- **自动**：结合内容判断用途，显示本次实际动作。单独一句话无法判断是草稿还是收到的消息时，默认改写；多人对话或处境描述通常分析。
- **改写**：保留原意和承诺范围，先展示可直接发送的成稿。
- **回复**：针对收到的消息提供推荐回复；多人对话无法确定你是谁时，提示补充身份和目标。
- **分析**：区分已知事实与可能解释，说明问题并给出行动建议。

切换动作会沿用本次原文和背景重新生成，生成中也可切换或停止。新一次取词恢复自动模式，并清空临时背景。

### 编辑原文与补充背景

点击原文旁的“编辑”可修改内容，也可校正截图识别文字。修改后点击“应用并重新生成”，输入期间不会逐字发送。

在“补充背景”中，可以选择“通用”“职场”“机关、事业单位、国企”或“家庭朋友”，并填写人物关系和沟通目标。例如：“我是小王，张经理是直属领导；拒绝今晚加班，不承诺明早一定交齐。”点击“应用并重新生成”后，本次结果会结合这些背景重做。

场景决定使用哪些沟通参考资料，动作决定生成改写、回复还是分析。背景仅用于本次任务；多人对话需要回复但身份不明时，应用会提示补充信息。

### 查看、复制与重做

改写和回复先展示一版话术，解释在“为什么这样说”中展开。主按钮“复制话术”只复制成稿；分析结果提供“复制分析”。“更多操作”可以复制包含解释的完整结果。

生成未完成或仍需补充信息时，主复制按钮不可用。重新生成、切换动作或应用修改后保留上一版完整结果，可以展开查看或点击“返回上一版”，同时恢复对应的原文、动作和背景。新一次取词开始独立任务。

快捷键可在“使用设置”中修改。与其他翻译软件同时运行时，请为它们设置不同的快捷键。

开启静默模式后，取词只显示不抢焦点的小浮窗，可复制主要内容或展开完整窗口。成功生成后 12 秒自动隐藏；需要补充信息或发生错误时保留。

## 能做什么

| 功能               | 用途                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| 划词与截图取词     | 从当前应用取得中文消息或待发送的话术                                       |
| 剪贴板与手动输入   | 不方便划词时，复制或直接输入内容                                           |
| 自动与动作切换     | 先自动生成，再按需切换改写、回复或分析                                     |
| 原文校正与背景补充 | 编辑识别文字，补充场景、人物关系和沟通目标                                 |
| 结果复制与上一版   | 分别复制话术、分析或完整结果，重做后可返回上一版                           |
| 沟通 Skills        | 结合职场、家庭、朋友等背景；明确选择机关、事业单位、国企时加入对应处境资料 |
| 流式结果与静默浮窗 | 边生成边查看，也可只显示不抢焦点的小浮窗                                   |
| 自动复制           | 按需将完整结果复制到剪贴板，默认关闭                                       |
| 本机历史与收藏     | 按需保存结果，默认关闭；普通记录保留最近 100 条，收藏单独保留              |

应用内置原有人情世故资料，以及 `workplace-communication` 和 `tizhi-skill` 的沟通参考资料，按所选场景组合使用。机关、事业单位、国企的专属资料仅在明确选择该场景时加入。

Skills 位于 [`Resources/Skills/`](Resources/Skills/)，来源与固定版本见 [知识库来源](Resources/Skills/SOURCES.md)。模型需能按提示返回 JSON Lines，应用逐段显示主要内容和解释；未按协议返回的结果会提示重试。

## 隐私与数据

- API Key 保存在 `~/Library/Application Support/com.chulan.renqingadvisor/credentials.json`，不额外加密；目录权限为 `0700`，文件权限为 `0600`，限制为当前用户访问。模型名称和服务地址保存在本机偏好设置中。
- 升级后首次读取密钥时，会尝试迁移旧版钥匙串记录。本机文件写入并回读确认成功后才清理旧记录；失败会显示提示，可点击“重新读取”重试。本机文件损坏时会报错并保留文件，不会静默回退到旧密钥。
- 只有你触发处理时，应用才会把原文、已应用的补充背景和 Skills 提示词发送到你配置的服务。切换动作、应用原文或背景、重新生成都会发起新请求。截图通过 Apple Vision 在本机识别，发送给模型的是识别后的文字。
- “验证连接”会向该服务发送一条 `ping` 请求。模型服务的数据保留规则由服务提供方决定。
- 历史保存默认关闭。开启后，原文、完整结果、处理动作、补充背景、时间、模型和取词来源会以 JSON 文件保存在本机，不额外加密。只保存完整成功的结果，旧版记录仍可查看、收藏和删除。打开历史只还原已保存内容，不自动请求模型。
- 关闭历史保存不会删除已有记录。历史文件位于 `~/Library/Application Support/com.chulan.renqingadvisor/history.json`。
- 结果自动复制默认关闭。启用后，系统剪贴板会包含生成的内容，请留意其他应用的剪贴板访问。

发送前请自行检查姓名、公司信息和不宜交给模型处理的内容。模型可能误解语气或关系，最终发出的表达由你决定。

## 清除密钥与卸载

“设置 → 服务 → 清除密钥”会清空本机密钥，并清理旧版钥匙串中的密钥。模型、服务地址、历史和收藏不受影响；清理旧钥匙串失败时会显示提示，需重新读取重试。清除后会保留一个不含密钥的本机文件，避免旧记录被重新迁入。

macOS 仅将 `Jeff.app` 移到废纸篓不会删除应用数据。完整卸载请按以下顺序操作：

1. 退出其他版本的 Jeff，在当前版本中清除密钥，确认没有旧钥匙串清理失败提示。旧版本共用该钥匙串记录，清理后也会失去此密钥。
2. 退出 Jeff，将“应用程序”中的 `Jeff.app` 移到废纸篓。
3. 在 Finder 使用“前往文件夹”打开 `~/Library/Application Support/com.chulan.renqingadvisor/`，删除该目录。此步骤也会删除历史和收藏，请先确认不再需要这些数据。
4. 如需一并清除模型、服务地址和快捷键等偏好设置，删除 `~/Library/Preferences/com.chulan.renqingadvisor.plist`，然后重新登录 macOS，使偏好设置缓存失效。

覆盖安装和升级会保留应用数据。安装包不携带开发者的密钥；重装后读到已有密钥，来自当前用户保留的本机数据或尚未迁移的旧钥匙串。

## 本地开发

需要 Apple Silicon Mac、macOS 14 及以上，以及包含 `swiftc` 和 `swift-format` 的 Apple 开发工具。当前已在 Apple Swift 6.1.2 下构建，无第三方运行时依赖。

安装 Command Line Tools 后，在仓库根目录执行：

```bash
xcode-select --install
git clone https://github.com/Chulan-824/Jeff.git
cd Jeff
make lint
make typecheck
make bundle
```

`make bundle` 生成根目录下的 `Jeff.app`，默认使用 ad-hoc 签名，不需要个人开发证书。`make run` 构建并启动；`make install` 构建后安装到 `~/Applications/Jeff.app`，会覆盖该位置的旧版本。请先退出旧版本，避免同时占用快捷键。

源码位于 `Sources/Jeff/`，图标源文件和运行时资源位于 `Resources/Icons/`。应用保留原有 Bundle ID `com.chulan.renqingadvisor`，以兼容早期版本的偏好设置和历史目录。不同签名的构建替换旧版后，首次迁移旧密钥可能要求钥匙串授权，辅助功能也可能需要重新授权。

取词与处理动作的交互约定、本轮实机验收记录及未覆盖项见 [交互说明](docs/INTERACTION.md)。

## 打包与发布

```bash
make package
```

首次打包需要 Python 3.10 及以上和网络连接，会在 `.build/dmg-venv/` 中安装固定版本的 `dmgbuild`，仅用于生成安装窗口布局，不会进入应用。打包过程无需操作 Finder，也无需授予自动化权限。

产物位于 `dist/`，包含 `Jeff.app`、按版本命名的 DMG 和 `SHA256SUMS.txt`。DMG 内提供应用图标、指向“应用程序”的入口和中文拖拽提示。DMG 与校验文件用于上传 GitHub Releases，构建产物不提交到 Git。仅需生成 DMG 时可执行 `make dmg`。

版本来自 `Resources/Info.plist`。签名、公证与发布步骤见 [发布说明](docs/RELEASING.md)。

## 限制与反馈

截图识别对横排、单栏文字效果更稳定。聊天气泡、多栏或竖排内容可以关闭“OCR 合并同段落换行”。取词是否成功也取决于目标应用是否支持辅助功能或复制操作。

目前没有自动更新，需要从 Releases 手动下载新版本。遇到问题请通过 Issues 提供系统版本、芯片、应用版本和脱敏后的复现步骤，不要上传 API Key 或私人聊天记录。
