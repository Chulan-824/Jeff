# 取词与处理动作交互

## 本次实现

划词、截图、剪贴板和手动输入只负责取得原文。有效取词立即进入自动处理；手动输入点击“开始处理”。结果窗口可切换自动、改写、回复、分析，切换时沿用本次原文和已应用的背景重新生成。

- 自动显示实际采用的动作；孤立单句默认改写，多人对话通常分析。
- 原文可展开、编辑并统一应用，也用于校正截图识别结果。
- 背景可选填场景、人物关系、沟通目标。输入期间不发送请求，点击应用后重做；新一次取词清空背景并恢复自动。
- 改写和回复先展示一版成稿，“为什么这样说”单独展开。主按钮只复制话术，分析则复制分析；更多菜单提供完整结果。
- 回复缺少关键身份时提示补充背景，禁用话术复制；分析可以先描述已知事实和局限。
- 重做保留上一版完整结果，可以直接返回；未完成内容不自动复制或保存。停止、切换动作和新任务取消旧请求，旧请求不得覆盖当前结果。
- 静默浮窗展示实际动作和主要内容，可展开处理；需要补充信息或发生错误时保留窗口。
- 历史增加动作、背景和结构化结果。旧记录继续显示完整结果，查看历史不请求模型。

应用按场景组合原有人情世故资料与社区资料，用户通过动作和场景控制用途。社区资料随应用打包，来源、固定版本和许可证见 [SOURCES.md](../Resources/Skills/SOURCES.md)。

## 本机验证记录

日期：2026-11-05。验证对象：仓库根目录构建的 `Jeff.app`，原生 macOS 窗口，服务为已配置的 DeepSeek / `deepseek-chat`。使用虚构的沟通示例，未开启历史保存和自动复制，未修改服务配置或授予系统权限。

| 场景               | 结果与证据                                                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------------ |
| 单句自动改写       | 真实模型返回成稿，窗口显示自动选择的改写动作和独立解释。                                                           |
| 仅复制话术         | 点击主按钮后在原文编辑器粘贴核对，剪贴板只有成稿，不包含解释。取消编辑保留原文。                                   |
| 编辑原文           | 将单句改为三人群聊，应用后使用新原文生成。                                                                         |
| 多人对话自动分析   | 显示核心判断与建议，可复制分析；没有因缺少用户身份阻断分析。                                                       |
| 切换回复           | 同一群聊缺少用户身份时提示补充信息，复制话术按钮禁用。                                                             |
| 补充背景           | 选定机关、事业单位、国企场景，填入人物关系和目标；统一应用后重新生成，场景参考资料成功加载。                       |
| 保留拒绝与承诺范围 | 目标为“拒绝今晚加班，不承诺明早一定交齐”；最终构建返回“今晚我无法加班……明早我无法保证全部交齐”，没有编造拒绝理由。 |
| 上一版恢复         | 展开上一版并返回，立即恢复对应结果、动作和背景，没有进入生成状态。                                                 |
| 生成状态           | 原生窗口显示进度与停止按钮，生成完成前复制按钮禁用。                                                               |

明确拒绝的示例在验收中曾被模型改成部分接受，已将用户目标约束放在场景参考之后，并加入输出前的立场核对；上述最终构建复验通过。提示词不能保证所有模型、所有输入均遵守目标，发送前仍需核对措辞。

静态检查与构建：`make lint`、`make typecheck`、`make bundle` 均通过。编译仍有既有 `CGWindowListCreateImage` 在 macOS 14 弃用的警告，本次未迁移截图 API。
