# Jeff 1.0.0 预览版

把想说的中文，翻译成更得体的中文。

这是 Jeff 的首个开源预览版。支持 macOS 14 及以上的 Apple Silicon Mac，使用划词、截图、剪贴板或手动输入取得中文内容，再结合沟通 Skills 给出话术改写和接话建议。

## 下载

下载 `Jeff-1.0.0-macos-arm64.zip`，解压后将 `Jeff.app` 拖入“应用程序”目录。`SHA256SUMS.txt` 可用于核对下载文件。

此版本使用 ad-hoc 签名，未经过 Apple Developer ID 签名和公证。macOS 可能阻止首次打开，确认来源后请按系统“隐私与安全性”中的提示处理。组织管理的设备应遵循其软件运行策略。

## 首次使用

- 应用常驻菜单栏，从图标菜单打开设置。
- 填写自己的 API Key、模型和 Base URL，支持 DeepSeek、OpenAI 及兼容 Chat Completions 流式接口的服务。
- 默认 `⌥⌘D` 划词处理，`⌥⌘S` 截图取词；权限和快捷键可在设置中管理。
- 自动复制和本机历史默认关闭，可按需开启。
