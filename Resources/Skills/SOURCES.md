# 沟通知识库来源

Jeff 使用自身的统一动作与输出协议，按场景组合知识库；不执行社区技能中的脚本，也不要求用户切换技能名称。

## 内置人情世故知识库

`references/` 保留原有家庭、恋爱、朋友、职场和社交资料。`SKILL.md` 是 Jeff 的应用协议，已适配自动、改写、回复与分析。
